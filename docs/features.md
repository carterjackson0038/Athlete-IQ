# MVP feature checklist

The current MVP scope has eight core feature bullets, and **all 8 are implemented**. This checklist covers the agreed scope; it is not a claim that the app is production-ready.

## Authentication

- [x] Signup
- [x] Login

## Study

- [x] AI study plans from a goal or explicitly selected study materials (Gemini, with a local fallback)
- [x] Upload notes (saved locally in this browser)
- [x] Upload images (saved locally in this browser)

Friends and leaderboards are intentionally outside the current scope.

## Gamification

- [x] XP
- [x] Levels
- [x] Badges

## Supporting dashboard features

- [x] Today's mission and focus timer
- [x] Assignment list
- [x] Study Seasons with exam countdown (saved on the current device)
- [x] Study materials shelf with download and remove controls (files stay on this device)
