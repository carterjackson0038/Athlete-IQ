# Roadmap and progress

## Current checkpoint

The eight core MVP capabilities in the current scope are implemented. See [the feature checklist](features.md) for that scope. This checkpoint does not mean production readiness; account-wide data sync, operational hardening, and deployment still need decisions and work.

- [x] Signup and login
- [x] Profile onboarding
- [x] Personalized dashboard

### Sprint 2 — Study Seasons

- [x] Add exam target, date, and difficulty
- [x] Show an exam countdown
- [x] Upload notes and images into a private, device-local study shelf
- [ ] Sync seasons across devices

### Sprint 3 — AI Coach

- [x] Generate study plans with Gemini
- [x] Send only subject, goal, and time unless the user selects study files
- [x] Include selected notes, PDFs, or images when a user chooses them for a plan
- [x] Keep a local planner fallback

### Sprint 4 — XP, Levels, and Badges

- [x] Award XP for daily missions and a finished focus session
- [x] Show levels and XP progress
- [x] Award visible badges from earned XP milestones
